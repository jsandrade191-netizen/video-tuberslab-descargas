# Video TubersLab — Descargas

Instaladores de **Video TubersLab**, el editor de video de la academia **TubersLab**.

👉 Descarga la versión más nueva en **[Releases](../../releases/latest)**:

| Tu computador | Archivo |
|---|---|
| Windows 10 u 11 | `Video-TubersLab-Windows.exe` |
| Mac con chip Apple (M1, M2, M3, M4…) | `Video-TubersLab-Mac-chip-M.dmg` |
| Mac con procesador Intel | `Video-TubersLab-Mac-Intel.dmg` |

Para usar el programa necesitas un **código de activación** que te da tu profesor.
Desde la versión 1.2.0, en Windows la app se actualiza sola.
